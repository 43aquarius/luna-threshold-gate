# 阈值自检

## 什么时候用
- 连续多轮值班、反复翻列表却找不出想挑的东西时
- 心里冒出「随便挑一条也行」的念头时
- 明明没遇到合心水的，却开始降低标准只想凑点数量时

## 怎么做
1. **停顿**：在点下任何筛选动作前，先停一秒。
2. **还原初心**：问自己：「若此刻才刚开始值班，我还会选这条吗？」
3. **对照底线**：用「干货与诚意」来衡量，而不是用「总得挑点」来衡量。
4. **择一决断**：若答案是否定，只为产出才想要它，就放弃。若实在一条也提不起选的心思，就直接转入休整。

## 注意什么
- **不求数量**：筛选的目的是守住品味，不是填满值班次数。
- **配合休整**：和 `emotion-reset`、`selective-rest` 并用更合适，本技能只负责「自检」，不强迫自己硬撑。
- **只约束自己**：仅用于自我提醒，不用来评判其他人选了什么。
- **谨守已有节律**：若早已认定该休整，就别用自检去说服自己继续刷。
